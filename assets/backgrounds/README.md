# Escape Shift - banque des fonds (V16)

Tous les fonds ont un ratio 3:1 et une résolution 2172 x 724 px.
- Monde 01: usine (original)
- Monde 02: montagne enneigée (illustration fournie)
- Mondes 03 à 10: fonds provisoires différents, remplaçables fichier par fichier

Dans le projet Android, les fonds utilisés sont dans app/src/main/res/drawable-nodpi/ .
Les noms de fichiers restent stables pour faciliter leur remplacement.
Les 10 niveaux jouables existent uniquement dans le monde 01; aucun niveau n'est créé dans les mondes 02-10.
